# Amit — Graphic Designer Portfolio

React + Vite + GSAP/ScrollTrigger + Lenis + Tailwind + Three.js (@react-three/fiber, drei).
Setup and animation patterns adapted from adrianhajdin/award-winning-website (no Zentry assets used).

- Edit all text, projects, skills and contact info in `src/constants/content.js`
- Replace project images: drop files in `public/projects/` and set `image: "/projects/name.jpg"`
- Run: `npm install` then `npm run dev` (http://localhost:5173)
- Build: `npm run build`
